# GitHubプロフィール要件定義

## 目的

GitHubプロフィールを、就職活動で見られたときに制作経験と担当範囲が伝わる入口として整理する。

## 公開方針

- 表示名は個人情報を出しすぎないように `Akihiro` とする。
- 技術バッジは多用せず、作品ごとの実装内容、担当範囲、成果を優先して書く。
- 公開に向かない内部ツールや、個人情報を含むファイルは公開しない。
- 画像はVCLとHoppyの概要画像を使い、本人写真や権利上扱いにくい素材は載せない。

## 掲載内容

- ポートフォリオサイトへのリンクを掲載する。
- VCL、Hoppy、Joy-Con入力検証、学生データ分析AWARD 2025を代表作品として扱う。
- Hoppyは、Python / Flask / MySQL / HTML / CSS / JavaScriptを使用したことと、コミュニティ機能・サポート機能の担当範囲を書く。
- Hoppyの開発時間は、個人時間ではなくチーム合計開発時間として `1044時間` と表記する。
- 学生データ分析AWARD 2025は、公開記事 `https://techplay.jp/column/2101` へリンクする。

## 運用

- 新しい公開用リポジトリを作った場合は、プロフィールREADMEのWorks表に追加する。
- READMEの更新は、GitHub上の差分で読みやすい粒度に分け、日本語のコミットメッセージでpushする。
- テキストファイルはLF改行で扱い、環境差で不要な差分が出ないようにする。
